# Swasti Nayak's README

Welcome, **Swasti Nayak**! This is your personal workspace for the tryouts. Please read the rules below carefully before you start.

## The Golden Rule

- **All of your work must stay strictly inside this folder** (`students/SwastiNayak/`).
- **Never change, rename, move, or delete anything outside your own folder.** This includes other students' folders, shared files, and repository configuration. Doing so may cause your submissions to be rejected.

## Where to Put Your Work

Your folder contains an `Assignments` folder with three subfolders:

| Assignment | Location |
|------------|----------|
| Assignment 1 | `students/SwastiNayak/Assignments/Assignment1/` |
| Assignment 2 | `students/SwastiNayak/Assignments/Assignment2/` |
| Assignment 3 | `students/SwastiNayak/Assignments/Assignment3/` |

- Create all files for a given assignment **inside that assignment's folder**.
- Do not mix files from different assignments in the same folder.

## How to Submit

1. Do your work on a branch (do **not** commit directly to `main`).
2. Place your files in the correct `AssignmentN` folder.
3. Open a **separate Pull Request for each assignment**, and submit it in the respective assignment PR.
4. Make sure your PR only touches files inside your own folder.

## Quick Checklist Before You Submit

- [ ] All files are inside `students/SwastiNayak/`.
- [ ] Files are in the correct `AssignmentN` folder.
- [ ] Nothing outside my folder was changed.
- [ ] One PR per assignment.
